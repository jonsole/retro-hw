# Park the 12.5 ns memory cycle

Retro-z80's 12.5 ns experiment is parked until the KS3 board and a faster DMA engine. When it returns, revision 1.1 adds deciding on `req & ~ack` (cycles can start on back-to-back clocks) and an optional per-slot read-delay table (latency is 4 or 5 clocks by slot); details in spec open point D5.

## Considered Options

- Pad every read to 5 clocks and keep one `RD_DELAY`: rejected, because the Z80 at 20 MHz has its byte one clock before it takes it, so one more clock is a wait it cannot make.
