# 0013. Park the 12.5 ns memory cycle; plan revision 1.1

| | |
|---|---|
| Status | Accepted (parked) |
| Date | 8 November 2026 |
| Decided by | Jon ("let's park 12.5ns"), with the retro-z80 session |
| Applies to | `rtl/dmac.v`, `rtl/sram_ctl.v`; spec `docs/spec/dmac.md` |

## Context

Retro-z80's fast-memory experiment gives 8 cycles per 100 ns slot. Cycles can start on back-to-back clocks, and the read latency is 4 or 5 clocks depending on the slot.

## Decision

Park it until the KS3 board and a faster DMA engine. When it returns, revision 1.1 adds (1) decide on `req & ~ack`, and (2) an optional per-slot read-delay table. Padding every read to 5 clocks is rejected: the Z80 at 20 MHz has no spare clock.

## Consequences

- Recorded in spec open point D5.
- Both changes are compatible: no new ports, today's builds unchanged.
